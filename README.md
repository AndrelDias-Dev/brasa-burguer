# Brasa Burger

Site estático e responsivo para montar pedidos e enviá-los pelo WhatsApp. Os produtos, preços e o número de telefone são **fictícios** para demonstração.

## Personalizar

Edite `STORE` no início de `js/main.js` para trocar o número de WhatsApp (`DDI + DDD + número`, só dígitos), nomes, descrições e preços. As imagens dos três lanches ficam em `assets/images/`.

Para visualizar, sirva a pasta do projeto com um servidor HTTP local e abra `index.html`. Não é necessário instalar dependências ou compilar o site.
